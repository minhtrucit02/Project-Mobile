## Báo cáo

### Đề tài

- **Tên đề tài:** Xây dựng ứng dụng bán giày bằng Flutter

### Mô tả

Dự án này phát triển một ứng dụng bán giày trực tuyến trên thiết bị di động sử dụng **Flutter** và **Firebase**. Ứng dụng hỗ trợ người dùng:

- Duyệt sản phẩm giày theo thương hiệu, giá, kích cỡ...
- Thêm vào giỏ hàng và thanh toán.
- Quản lý tài khoản, đơn hàng, sản phẩm (dành cho Admin).
- Giao diện hiện đại, hoạt động ổn định trên Android.

### Công nghệ sử dụng

- **Frontend:** Flutter (Dart), Figma (thiết kế UI).
- **Backend:** Firebase (Authentication, Realtime Database).
- **Lưu trữ ảnh:** Cloudinary.
- **Công cụ:** Android Studio, VS Code, ChatGPT hỗ trợ.

### Cài đặt

1. **Cài đặt SDK:** Flutter SDK.
2. **IDE:** VS Code, Android Studio.
3. **Thiết bị:** Android Emulator hoặc thiết bị thật.
4. **Hướng dẫn triển khai:**
   - Tạo Project Firebase.
   - Kết nối Firebase với app (google-services.json).
   - Cài đặt các node dữ liệu mẫu: `/products`, `/users`, `/orders`.
